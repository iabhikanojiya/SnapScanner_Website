# Snap Scanner Website

Production-ready marketing website for the Snap Scanner Android app.

Built with Next.js 15, TypeScript, Tailwind CSS, Shadcn UI, Framer Motion, and Lucide Icons.

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```

## Deploy to Vercel

1. Push to GitHub
2. Import repo at https://vercel.com/new
3. Deploy
